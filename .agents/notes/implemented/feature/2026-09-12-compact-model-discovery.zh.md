# Agent Note: 紧凑的模型发现

Status: implemented

[English](2026-09-12-compact-model-discovery.md) | 中文

## Problem

大型提供方目录使展开的模型菜单难以浏览。独立的订阅登录行重复展示控件，即使用户只处理一个账户，也会占用 Models 设置空间。

## Decision

[输入区选择器](../../../../packages/client/ui-model-selection/README.zh.md) 保留 Model 和 Effort 面板。每次重新打开时，提供方分组默认收起。搜索匹配提供方和模型的名称与标识符，忽略大小写和空白字符，显示匹配模型，并在清空后保留原有浏览展开状态。目录顺序与包含提供方的模型标识仍具有权威性。

搜索和展开状态属于组件，不属于设置或 Session 数据。现有模型目录仍通过原生控制器加载目录并提交选择。模型发现无需更改 agent loop（智能体循环）、Session 格式、SDK 投影或上游 profile 组合。

[订阅页脚](../../../../packages/fi/client-ui-model-signin/README.zh.md) 使用一个原生提供方选择器，展示所选账户的状态与操作。选择账户既不会执行认证，也不会选择推理模型。运行中和已完成的尝试保留其提供方归属；模型采用详情使用折叠区。认证和凭据所有权仍由[订阅登录决策](2026-09-11-subscription-oauth-sign-in.zh.md) 定义。

[设置外壳](../../../../packages/client/ui-settings-general/README.zh.md) 将面板放入 body portal，防止侧边栏裁剪遮挡账户控件。窄视口使用全高面板、横向导航和可滚动分区，同时保留桌面布局与现有 slot。React DOM 提供 portal；实现不引入独立的覆盖层服务或路由 API。

## Alternatives considered

**四个常驻账户按钮。** 它们省去一次选择器交互，但保留重复的账户控件并占用窄屏空间。原生选择器通过一个支持键盘操作的控件提供所有已注册账户。

**始终展开或全局扁平化的目录。** 展开会显示数千行，扁平化则会模糊重复模型标识符所属的路由。提供方折叠区保留归属信息；搜索避免浏览无关模型。

**持久化菜单偏好或独立目录存储。** 选择模型不需要它们。局部展示状态避免新增设置、同步机制和上游控制器变更。

## Consequences

浏览提供方需要一次展开交互。搜索可跳过这一步，同时不改变当前模型或已存储账户。每次重新打开时，临时状态都会重置；现有目录仍是模型标识和推理选项的唯一真源。

聚焦的组件测试覆盖模型发现、实时目录变化、操作恢复与键盘焦点。浏览器验证使用构建后的 Web 组合，覆盖包含提供方的模型选择持久化、大型目录、窄屏布局与本地化控件。这些 UI 检查不能替代真实订阅推理或媒体验证。
